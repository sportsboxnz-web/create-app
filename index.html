Launch
Script

Seven steps. Fifteen minutes. Everyone leaves the room with CREATE running.

How to run this session

Block 15 minutes with the team. Work through the seven steps in order. The script tells you what to say — read it out, in your own words if you prefer. By the end, the team will have picked two reinforcement techniques and you'll have them running before anyone leaves the room.

Click each step to expand it. Time codes are guides, not stopwatches.

The Rule

Both reinforcement techniques activated before anyone leaves the room. No "we'll start it tomorrow."

1
The Shift Starter Card
"This one's simple. There's a laminated card that sits at the counter. Each week I'll flip it to one CREATE standard — that's the one we're focused on for the week. Nothing fancy, just a reminder of what we're working on."
How it worksEach week the manager picks the focus behaviour and turns the card to that standard. It stays visible at the counter all week. At the end of each shift, give a quick nod to anyone you saw nailing it.
How to run itArrive before the team. Pick this week's standard. Flip the card. During shifts, watch for that one behaviour. At the end of each shift, mention it — even just "Good work on the greetings today." Thirty seconds is enough.
2
The Floor Walk
"Once a shift I'll do a quick lap — maybe five minutes. I'm not checking up on anyone. I'm just looking for someone doing CREATE well. When I see it, I'll say so. Out loud, in front of the team."
How it worksPick a time each shift — usually mid-morning or just after lunch — and do a deliberate walk through the floor. Watch for one CREATE behaviour. When you see it done well, call it out publicly.
How to run itSet a phone reminder so it actually happens. Pick one behaviour to watch for that shift. When you see it: "Just noticed how you handled that customer — that's exactly what we're after." Keep it natural.
3
The Customer Story Debrief
"At the end of a shift — or at the start of the next one — one person shares a real customer interaction. Just a story. Something that happened. I'll tie it back to CREATE. No performance, no roleplay."
How it worksOne team member shares a real interaction — good, ordinary, or one that didn't quite land. The manager listens, then maps one part of it back to a CREATE standard. Two minutes, not a debrief session.
How to run itNominate who goes first before you leave today. Agree on when — end of shift or start of the next. Keep it low-key. Pick one CREATE moment from what they share and name it: "That right there — that's Explain Simply. Well done." Rotate who shares each time.
4
The WhatsApp Nudge
"Every morning I send one message to the group chat. One sentence. One CREATE behaviour. Done in ten seconds. Just keeps it front of mind without adding any meetings."
How it worksOne focused message to the store WhatsApp group each morning before shift. One behaviour, one prompt, nothing more. Over time it builds a rhythm — staff start to expect it.
How to run itSend it before the first staff member starts. Keep it to one sentence. Don't have time to write one? Jump to the 90 WhatsApp Nudges pack and pull one straight out of the list.
5
The Scoreboard
"We put one number on the whiteboard and track it for the week. Something simple — like how many website quotes we did, or how many greetings landed. It's not a competition. It just makes CREATE visible."
How it worksPick one measurable CREATE behaviour and track it on a whiteboard or printed sheet the whole team can see. Numbers on a wall change behaviour without anyone needing to say a word.
How to run itPick one metric — keep it simple and countable. Stuck for ideas? Jump to the 12 Scoreboard Ideas pack and pick one. Write it up before the team arrives.

Operating
System

The rhythm that keeps CREATE alive after the launch — every shift, every Monday, every Friday.

Ask Yourself Every Shift
Which CREATE behaviour did I reinforce today?

How to read this

Five rhythms make up the CREATE operating system. Three are yours alone — what you do each shift, each Monday, each Friday. The other two cycle across the whole store network: the weekly manager meeting, and the six-week micro install rotation that takes your team through every CREATE step.

Every Shift
Daily essential steps for managers
Run your chosen reinforcement technique — Shift Starter Card, Floor Walk, WhatsApp Nudge, Story Debrief, or Scoreboard.
Catch one person doing CREATE well. Name it out loud in front of the team.
If you hear a wrong phrase — correct it calmly and immediately. Reset to the standard.
Every Monday
Weekly Micro Install — 5 minutes
Name the one CREATE behaviour you're focusing on this week.
Demonstrate bad vs best — 60 seconds, no roleplay required.
Have each person say the phrase out loud once. That's the install.
Every Friday
Recognition + behaviour check
Call out one CREATE win publicly — specific behaviour, specific person.
Complete the Behaviour Check for the week.
Identify the lowest-scoring letter — that's next week's focus.
Weekly Manager Meeting
CREATE pulse — 5 minutes
Share one behaviour reinforced this week.
Share one CREATE win from your store.
Name your focus behaviour for next week.
6-Week Micro Install Rotation
One CREATE step per week
Week 1 — Connect Quickly: "Welcome to Tile Depot!"
Week 2 — Really Listen: "Tell me about the project…"
Week 3 — Explain Simply: feature → benefit translation
Week 4 — Add Value: website quote function + project thinking
Week 5 — Take Responsibility: full quote read-back
Week 6 — End Memorably: name + project + invitation
Remember

The rhythm is the system. Miss a week and CREATE drifts; keep the rhythm and it runs itself.

12 Scoreboard
Ideas

One metric. One week. CREATE made visible.

How to use this pack

Pick one scoreboard per week. Write the metric on the whiteboard before the team arrives. Update it daily. Review it briefly on Friday. Change it the following week.

Two scoreboards per CREATE step — so you can rotate through the full framework in 12 weeks, or pick the ones most relevant to what you're seeing in your store right now.

Numbers on a wall change behaviour without anyone needing to say a word.

The Rule

One metric only. Keep it simple and countable. A rough tally is better than a precise number you never update.

C
Scoreboard 01
The 30-Second Greeting Tally
Connect Quickly
What you track

Number of customers greeted within 30 seconds this shift.

How to track it

Manager or nominated team member tallies every greeting observed on the floor during each shift. A simple tick on the whiteboard per greeting. Total it at end of shift.

Write on the board
Greetings within 30 seconds today: ______
Friday review
"We landed [X] greetings this week. Every single one of those customers felt welcomed the moment they walked in. Next week, let's see if we can keep every shift above [Y]."
Why it works

The greeting is the easiest CREATE behaviour to observe and the fastest to drift. Making it visible resets the standard without anyone needing to say a word.

Manager tip

Don't count greetings that miss the 30-second window — only tally the ones done right. Accuracy matters more than a high number.

C
Scoreboard 02
First Customer Response Time
Connect Quickly
What you track

How long before the first customer of the day was acknowledged.

How to track it

Manager notes the time the first customer enters and the time they were greeted. Track this each morning for the week — record the gap in seconds on the board.

Write on the board
First greeting today: ______ seconds after customer entered
Friday review
"Our average first response this week was [X] seconds. That's [better than / the same as] last week. We're aiming to keep it under 30 seconds every morning."
Why it works

The opening of the day sets the standard for the shift. Tracking it creates accountability from the first minute the door opens.

Manager tip

This one is quick to run — one observation per morning. It takes 30 seconds of manager attention to make a visible point to the whole team.

Really Listen

Essential Step"Tell me about the project you're working on." — every engagement.

R
Scoreboard 03
Discovery Question Tracker
Really Listen
What you track

Number of times the project discovery question was used this shift.

How to track it

Manager listens for the exact phrase "Tell me about the project you're working on" during floor walks. Tally each time it's used correctly. One tally mark per interaction observed.

Write on the board
Discovery questions asked today: ______
Friday review
"We asked the discovery question [X] times this week across the interactions I observed. That means [X] customers felt heard before we recommended anything. Let's make it automatic."
Why it works

Advice given before listening feels like a sales pitch. Tracking the discovery question makes listening a visible, measurable behaviour — not just an expectation.

Manager tip

Only count the exact phrase or a clear equivalent — not "Can I help you." The specificity is the point.

R
Scoreboard 04
Project Confirmed Counter
Really Listen
What you track

Number of interactions where the team member confirmed understanding before recommending.

How to track it

During floor walks, listen for the confirmation step — "So if I've got this right…" or "Just to confirm…" Tally each time a team member reflects back what they've heard before moving to products.

Write on the board
Confirmations before recommendations today: ______
Friday review
"We confirmed understanding [X] times before making recommendations this week. That's [X] customers who felt properly listened to. Next week let's make it a habit, not a highlight."
Why it works

Most staff ask the discovery question but skip the confirmation. Tracking confirmation closes the loop — it proves the listening actually happened.

Manager tip

This one's slightly harder to observe than the greeting. Use it in weeks when you're doing regular floor walks and can listen to full interactions.

Scoreboard 05
Plain Language Wins
Explain Simply
What you track

Number of times a technical term was translated into plain language this shift.

How to track it

During floor observations, listen for the translation moment — "[term], which means [benefit]." Tally each time a team member explains a feature in customer-friendly language unprompted.

E
Scoreboard 06
Three Options Rule
Explain Simply
What you track

Number of interactions where the team member offered two or three options — not more.

How to track it

Observe product selection conversations. Tally each time a team member narrows choice to two or three clear options with a recommendation, rather than showing an overwhelming range.

Write on the board
Curated options presented today: ______
Friday review
"We gave customers a curated choice [X] times this week. Fewer options, better decisions. Next week let's make sure every product conversation ends with a clear recommendation."
Why it works

Showing 20 options creates decision fatigue. Two or three curated choices with a recommendation builds customer confidence and shortens the sales cycle.

Manager tip

This is a coaching signal too — if the number is low, run a quick Bad vs Best demo in Monday's micro install showing the difference between overwhelming and curating.

Add Value
What you track

Number of interactions where a complementary product or category was mentioned.

How to track it

During floor walks and counter observations, tally each time a team member proactively mentions bathware, laminate, maintenance products, trade supplies, or any category beyond what the customer asked for.

Write on the board

Most customers don't know the full range Tile Depot carries. Tracking full project conversations builds the habit of thinking beyond the immediate request.

Manager tip

Pair this with a Monday micro install — spend two minutes showing the team how to bridge from tiles to bathware naturally: "Since you're doing the whole bathroom, have you thought about your vanity?"

Personalised Goodbye Counter
End Memorably
What you track

Number of closing interactions that included the customer's name or a project reference.

How to track it

During floor walks near the counter, listen for the close. Tally each time a team member references the customer's project, uses their name, or issues a genuine invitation to return — rather than a generic "Thanks, have a good day."

Write on the board
Memorable closings today: ______

"We gave [X] personalised goodbyes this week. Those customers didn't just have a transaction — they had an experience. That's what brings them back and what they tell their friends about."
Why it works

The close is the last thing a customer remembers. Research shows endings disproportionately shape the overall memory of an experience. Making memorable closes visible raises the standard without a lecture.

Manager tip

At Friday's recognition moment, share one specific closing line a team member used this week — quoting it exactly. Real examples spread faster than instructions.
